# **App Name**: Rooted: Ambient Care Platform

## Core Features:

- Secure Role-Based Authentication: Manages user login and redirects based on Guardian or Facility Admin roles, ensuring server-side authentication protection with NextAuth.js.
- AI-Powered Care Insights Tool: Provides Guardians with AI-generated summaries of daily or weekly reports and highlights unusual activity detected from ambient care data.
- Guardian Portal Dashboard: A personalized and responsive dashboard for guardians to monitor their loved ones' status, view aggregated reports, and manage associated devices.
- Admin Portal Management Interface: A centralized, responsive interface for facility administrators to oversee all deployed devices, manage events, and view overall system health.
- Reusable Device Status Indicator: A standardized visual component for displaying the real-time operational status (active, inactive, maintenance) of individual care devices across all portals.
- Responsive Navigation System: Provides intuitive, role-specific navigation for both Guardian and Admin portals, adapting fluidly between desktop sidebars and mobile drawers/bottom tabs.
- Global UI Feedback: Implements consistent user interface feedback for global application states, including loading indicators with skeletons and user-friendly error messages.

## Style Guidelines:

- Primary color: Muted blue (`#4D76B2`). This color aims to evoke trust, stability, and calm, perfectly aligning with the core concept of an ambient care platform.
- Background color: Very light blue-grey (`#EAF0F9`). This subtly tinted neutral background provides a clean, open, and serene canvas that's gentle on the eyes for extended viewing of reports and dashboards.
- Accent color: Clear aqua-blue (`#5CCEE0`). A vibrant yet fresh analogous color that introduces dynamism and highlights interactive elements and key information without disrupting the overall sense of calm.
- Body and headline font: 'Inter' (sans-serif). Chosen for its modern, clean, and highly legible characteristics, it's suitable for both headings and detailed content, ensuring clarity in data display and reports.
- Clean, minimalist line icons. These icons are selected to clearly communicate function and status at a glance, maintaining a modern and uncluttered aesthetic essential for a data-rich care platform.
- Adaptive and responsive layouts optimized for diverse content. This includes role-based dashboards and distinct navigational patterns (fixed sidebars for desktop, collapsible drawers/bottom tabs for mobile) to ensure usability across devices.
- Subtle and functional animations. Animations, such as gentle pulse effects for active status indicators, are incorporated sparingly to enhance user perception and provide gentle feedback without causing distraction.
